# SkiNC

North Carolina skiing, right now.

## Status

Repository initialized for Cloudflare Pages. The original website files and interactive trail maps have **not yet been migrated**. Do not treat this README-only branch as a production site.

## Planned snow-first experience

- Live 24-hour, 3-day and 7-day resort-level snowfall forecasts, labeled as forecasts
- Observed snowfall and snow depth separately labeled when reliable reports are available
- Storm-watch homepage and forecast uncertainty
- Summit/base temperatures, snowmaking windows and webcam links
- Existing resort pages and custom trail maps preserved during migration

## Deployment

Once the website source is migrated, configure Cloudflare Pages with the correct framework settings, output directory, and branch `main`. Do not route the production custom domain to this README-only repository.
